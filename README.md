# APTeN-MSA-BE

## 프로젝트 소개

APTeN은 입주민과 관리자가 함께 사용하는 스마트 아파트 통합 관리 시스템입니다.

1차 프로젝트에서는 Spring Boot 단일 서버 구조로 방문차량, 주차, 시설예약, 게시판, 세대 관리 기능을 구현했습니다.
2차 프로젝트에서는 기존 기능을 도메인별 서비스로 분리하고, Gateway, Kafka, Redis, WebSocket, FCM 등을 적용하여 MSA 구조로 확장했습니다.

입주민은 차량 등록, 방문차량 등록, 시설 예약, 게시판 이용, 알림 확인 등을 사용할 수 있고, 관리자는 세대 승인, 차량 승인, 시설/GX 프로그램 관리, 주차 현황 확인, 공지사항 관리 등을 수행할 수 있습니다.

## 핵심 설계 포인트

### 1. Monolith에서 MSA 구조로 확장

1차 프로젝트의 단일 Spring Boot 서버 구조를 도메인별 서비스로 분리했습니다.

* auth-service
* apartment-complex-service
* household-service
* parking-vehicle-service
* facility-reservation-service
* board-service
* notification-service

각 서비스가 자신의 도메인 책임을 가지도록 분리하고, 공통 기능은 common 모듈로 관리했습니다.

### 2. Gateway 기반 인증 처리

Gateway에서 JWT를 검증하고, 내부 서비스에는 인증된 사용자 정보를 헤더로 전달했습니다.

```text
Client
  → Gateway JWT 검증
  → X-User-Id / X-Role / X-Complex-Id 전달
  → 내부 서비스 라우팅
```

이를 통해 각 서비스가 인증 검증을 반복하지 않고, 비즈니스 로직에 집중할 수 있도록 구성했습니다.

### 3. Kafka 기반 이벤트 구조

서비스 간 직접 의존도를 줄이기 위해 Kafka 이벤트 기반 구조를 적용했습니다.

사용자, 세대, 차량, 시설 이용, 게시판 이벤트 등을 Kafka로 발행하고, 필요한 서비스에서 수신하여 내부 데이터를 동기화하도록 구성했습니다.

### 4. Outbox 패턴 적용

DB 저장과 Kafka 발행 사이의 이벤트 유실을 방지하기 위해 Outbox 패턴을 적용했습니다.

도메인 데이터 저장과 Outbox 이벤트 저장을 하나의 트랜잭션으로 처리하고, OutboxRelay가 주기적으로 Kafka에 이벤트를 발행하도록 구성했습니다.

### 5. Redis 활용

Redis는 단순 캐시뿐 아니라 여러 실시간/동시성 기능에 활용했습니다.

* JWT 블랙리스트
* 좌석 임시 선점 TTL
* 주차 센서 상태 캐시
* ShedLock 저장소
* 주차 구역 카운터 캐시

### 6. 실시간 기능 처리

사용자 경험이 중요한 기능에는 실시간 통신을 적용했습니다.

* 주차 현황: SSE
* 인앱 알림: WebSocket
* 웹 푸시 알림: FCM
